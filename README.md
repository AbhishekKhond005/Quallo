# Quallo

Quallo is a local desktop project planner for game development. The sample Nightfall board shows a vertical slice moving from backlog through playtest to completion.

## Run from source

Install a JDK (21 or newer), then build and launch on Linux.

```sh
./scripts/build.sh
java -jar build/input/quallo.jar
```

Quallo keeps its workspace and attachments locally. The app uses Java Swing and runs without a browser or server.
